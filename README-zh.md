# MicMonitor

[English](README.md) | 中文

macOS 菜单栏小工具:把麦克风声音**实时直通**到你选定的输出设备(耳机),并可调节混入音量。
适合"戴着降噪耳机听歌,听不到同事叫你"的场景——音乐仍由系统正常播放,本应用只额外叠加麦克风声音。

<img width="700" height="1010" alt="image" src="https://github.com/user-attachments/assets/e77f4ab7-6885-44e7-9a95-0efa444cb720" />

- 菜单栏常驻图标(可选开启 Dock 图标,点击弹出设置窗口)
- 可分别选择输入(麦克风)与输出(耳机)设备,默认跟随系统
- 混入音量 0%~200%(超过 100% 自动软限幅防爆音),支持一键静音
- 可选噪声门:电平低于阈值时不混入,避免持续底噪(带实时电平条辅助调阈值)
- 啸叫守护:检测到麦克风回授耳机声音时自动压低音量
- 低延迟模式 + 自适应缓冲:设备时钟不稳时自动放大缓冲消除卡顿
- 设备热插拔自动停止/恢复,默认设备变化自动跟随
- 中英双语界面(跟随系统语言)
- 无第三方依赖,通用二进制(Apple Silicon + Intel),最低 macOS 15

## 下载与首次使用

1. 在仓库的 **Releases** 页下载最新版 `MicMonitor.zip`(由 `v*` 标签触发 CI 自动构建发布);
   开发版可在 **Actions** 页选择最新一次成功构建下载 artifact。
2. 解压得到 `MicMonitor.app`,拖到 `应用程序` 或任意目录。
3. **因为是 ad-hoc 签名(无 Apple 开发者证书),首次打开会被 Gatekeeper 拦截**,任选一种:
   - 右键 `MicMonitor.app` → **打开** → 在对话框里再点"打开";
   - 或终端执行(去掉隔离属性,之后可直接双击):
     ```bash
     xattr -dr com.apple.quarantine /path/to/MicMonitor.app
     ```
4. 首次点"启用麦克风直通"会弹出麦克风权限请求,点允许。
   如果误点拒绝:菜单栏图标 → "打开系统设置" 直达 隐私与安全性 → 麦克风。
5. **注意:ad-hoc 签名每次重新构建后都会变,macOS 可能让麦克风权限失效**,此时执行:
   ```bash
   tccutil reset Microphone com.example.micmonitor
   ```
   然后重启 App 重新授权。

## 使用说明

| 选项 | 说明 |
|---|---|
| 输入设备 | 建议用"内置麦克风"。**不要选蓝牙耳机的麦克风**:蓝牙协议限制,启用麦克风会让耳机切换到通话模式(HFP),音乐音质明显下降。面板检测到输入/输出是同一台蓝牙设备时会给出黄色提示。 |
| 输出设备 | 选你正在戴的耳机,或"系统默认"自动跟随。 |
| 混入音量 | 0%~200%。100% 为原样增益;超过 100% 的部分经过软限幅,不会爆音。 |
| 噪声门 | 环境安静但耳机里有持续底噪时打开;看电平条把阈值调到"底噪之下、说话声之上"。起音约 10ms、释放约 400ms 的平滑,不会明显卡顿。 |
| 低延迟模式 | 默认开启,请求更小的设备 IO 缓冲以降低端到端延迟(减少"回声感")。设备跟不上时会自动回退标准缓冲。 |
| 在 Dock 中显示图标 | 默认关(纯菜单栏)。开启后点 Dock 图标弹出与菜单栏相同的设置窗口。 |
| 缓冲 | 面板底部显示当前缓冲水位(ms)与欠载/丢弃计数;不稳定时自适应缓冲会自动放大(橙色提示)。 |

## 常见问题

- **蓝牙耳机音质突然变差**:这是开了蓝牙麦克风的必然结果(HFP 协议),改用内置麦克风即可恢复。
- **有回声/啸叫**:耳机漏音被麦克风再次拾取。把混入音量调低、打开噪声门、或换密闭性更好的耳机;啸叫守护会自动压音量,但治本还是物理上拉开麦克风与发声单元的距离(如换用笔记本内置麦克风);音箱外放时不要开直通。
- **延迟偏高/有卡顿**:查看面板"缓冲"值与欠载计数;USB/蓝牙设备时钟漂移大时会周期性听到轻微跳变,自适应缓冲会自动调大水位改善。
- **排查问题**:面板点"复制诊断信息"(含版本、设备列表、权限、错误计数、最近日志),把它贴出来即可定位。

## 技术要点

- **架构**:优先创建私有聚合设备(输入子设备 + 输出子设备,输出做主时钟、开漂移补偿),用**单个 `AVAudioEngine`** 驱动——输入 tap 与输出渲染在同一 IO 周期、同一时钟域,无漂移(AU Lab passthrough 同款方案)。聚合创建失败回退双引擎 + 环形缓冲。
- **数据通路**:采集端 `installTap` → `AVAudioConverter` 统一为播放端规范格式(planar Float32)→ SPSC 无锁环形缓冲 → `AVAudioSourceNode` → `mainMixerNode` → 输出。
- **稳定性**:低延迟请求读回实际生效值;启动 2s 自检欠载;运行时每 3s 统计欠载+溢出,异常则按 ×1.8 递增放大水位(上限 ×6);自身重建触发的配置变化通知有 2s 抑制窗防死循环。
- **DSP**:增益逐样本线性斜坡;噪声门 attack 10ms / release 400ms;tanh 软限幅(阈值 0.8);啸叫守护检测持续顶限幅自动降增益。
- 渲染/采集回调内不分配、不加锁、不打日志;电平与计数全部走原子量,UI 以 ~15fps 定时读取。
